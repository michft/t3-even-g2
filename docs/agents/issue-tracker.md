# Issue tracker

Issues and PRDs live in `michft/t3-even-g2` on GitHub. "Local" means this fork,
not files in the checkout. Always pass `--repo michft/t3-even-g2` to `gh issue`
and `gh pr`; do not infer the destination from the fork's upstream remote.

- Read a report with `gh issue view <number> --repo michft/t3-even-g2 --comments`.
- Search open and closed issues before filing another report.
- Use `--body-file` for multiline issues, comments, and PR descriptions.
- Publish an issue or comment only when requested as part of the task.
- Agent-generated triage posts start with
  `> *This was generated by AI during triage.*`.
- A ready label does not authorize implementation, pushing, or creating a PR.
  An explicit request to implement an issue and open its PR authorizes that
  workflow; do not ask again for each step within it. Merging is separate.
- Link each PR to its accepted fork issue. Keep partial fixes open with `Refs`;
  use `Closes` only when the PR completes the issue's acceptance criteria.
- Upstream escalation needs evidence of an upstream defect and an explicit
  request. Never change the destination just because a shared playbook says so.

See the [maintainer workflow](../operations/even-g2-triage.md#maintainer-workflow).
